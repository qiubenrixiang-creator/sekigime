# 卓組みボード

ボードゲーム会の席決めツールです。
参加者の回答をもとに、卓の定員を守りながら、居心地のよい組み合わせを計算します。

通信を使いません。会場の電波が悪くても動きます。

---

## 使い方

### 参加者

1. URLを開いて「参加者として答える」
2. 9つの質問に答える（30秒ほど）
3. 表示された **4文字のコード** を幹事に伝える

### 幹事

1. 「幹事として卓を組む」
2. 名前とコードを入れて、参加者を追加していく
3. 1卓あたりの人数を決める（初期値は4名）
4. 「卓を組む」を押す
5. 必要なら、名前をタップして手で入れ替える
6. 「卓に置く札を印刷」で、各卓に置く紙を出せる

2回戦をやるときは「次のラウンドを組む」。前と同じ顔ぶれを避けて組み直します。

## 設計の考え方

### 全員揃ってから、まとめて計算する

診断した順に空いている卓へ入れていく方式だと、後から来た人ほど希望と違う卓に回ります。
このツールは全員の回答を集めてから一度に割り当てるので、順番による有利不利がありません。

### 揃える軸と、散らす軸を分ける

卓が居心地悪くなるのは、**会話量・テンポ・ゲームの重さ**が合わないときです。
静かに考えたい人とわいわい喋りたい人、長考する人とサクサク進めたい人が
同じ卓にいると、どちらも楽しめません。この3つは揃うように計算しています。

一方で **運まかせか戦略かの好み** は、違っていても問題になりません。
むしろ違う方が面白いので、あえて計算に入れていません。卓の紹介文に使うだけです。

### 初心者を孤立させない

初心者だけの卓ができると、誰もルールを説明できません。
「ルール説明ができる」と答えた人が各卓に散るよう、強めの重みをかけています。

### 途中で帰る人を重い卓に入れない

1時間超のゲームを途中で抜けられると、卓が成立しなくなります。
途中退出の予定がある人は、軽めの卓に寄せます。

### 手で直せる余地を必ず残す

当日は必ず想定外が起きます。遅刻、欠席、カップル、相性の問題。
計算結果はあくまで下書きなので、タップで入れ替えられるようにしました。
動かしたくない人は「固定」しておくと、組み直しても動きません。

## コードのしくみ

参加者のプロフィールは6つの数字です。

| 項目 | 範囲 | 意味 |
|---|---|---|
| weight | 0-4 | 軽いゲーム ← → 重いゲーム |
| strategy | 0-4 | 運まかせ ← → じっくり戦略 |
| talk | 0-4 | 静かに集中 ← → わいわい喋る |
| pace | 0-4 | 長考OK ← → テンポ重視 |
| exp | 0-2 | ほぼ初めて / 何回か / 説明もできる |
| leave | 0-1 | 最後までいる / 途中で帰る |

これを32進数3文字にまとめ、**4文字目に検査用の文字**を足しています。
打ち間違えるとその場で弾かれるので、違うプロフィールが黙って登録されることはありません。

使う文字は `23456789ABCDEFGHJKLMNPQRSTUVWXYZ` の32種類です。
`0` と `O`、`1` と `I` は読み間違えるので外してあります。

## ファイル構成

```
kumiban/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  ├─ model.js    質問文・卓の色・コードの変換  ← 文章を直すならここ
│  ├─ assign.js   割り当ての計算
│  └─ app.js      画面の動きと保存
└─ README.md
```

質問文を変えたいときは `js/model.js` の `QUESTIONS` だけを編集してください。
質問を足しても、軸（`axis`）が同じなら自動で平均されます。
ただし **軸ごとの選択肢の数を変えるとコードの桁が変わる** ので、
`encodeProfile` の計算も合わせて直す必要があります。

割り当ての重みづけを変えたいときは `js/assign.js` の先頭にある
`COST_WEIGHTS` と `PENALTY_*` を触ってください。

## GitHubへの上げ方

このフォルダの中身をそのままリポジトリに置けば動きます。
ビルドは不要です。

**ブラウザのドラッグ&ドロップはフォルダ構造が壊れることがあります。**
`css/style.css` のようにスラッシュ付きで表示されない場合は失敗しているので、
GitHub Desktop を使ってください。フォルダをそのまま扱えるので確実です。

公開はGitHub PagesでもVercelでも動きます。
サーバーの設定は要りません。

---

## 保存について

データはブラウザの localStorage に入ります。この端末から出ません。
別の端末とは共有されないので、**幹事はずっと同じ端末で操作してください。**

会が終わったら「この端末のデータをすべて消す」で片付きます。
